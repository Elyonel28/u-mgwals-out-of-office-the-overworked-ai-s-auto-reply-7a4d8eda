## Run it

```sh
node main.ts
```

It writes the single auto-reply (153 characters, one line) to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), validates the 1–159 character gate, and verifies the round-trip.
